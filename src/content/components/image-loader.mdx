## Usage

```astro
---
import ImageLoader from "@components/ImageLoader.astro";
import shot from "@images/project.jpg";
---

{/* Standalone — frame reserves aspect-ratio from the asset */}
<ImageLoader
  src={shot}
  alt="Project photograph"
  widths={[720, 1280]}
  sizes="40vw"
/>

{/* Parent owns sizing — fill the figure */}
<figure class="relative h-[80svh] overflow-hidden" style={`aspect-ratio: ${shot.width} / ${shot.height}`}>
  <ImageLoader
    src={shot}
    alt="Project photograph"
    class="absolute inset-0 size-full"
    preserveAspect={false}
    loading="eager"
    fetchpriority="high"
  />
</figure>
```

## Behavior

- Stage uses `bg-canvas` / `text-fg` so themes invert correctly (Figma `#f2f2f2` maps to the canvas token).
- Palm mark breathes while waiting; reduced-motion users get a static mark and an immediate reveal.
- Cached images (`img.complete`) skip the stage without waiting for a load event.
- Without JS, a `<noscript>` rule hides the stage so the photograph stays visible.
