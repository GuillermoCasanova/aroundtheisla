Per-image loading stage: a `bg-secondary/80` surface covering the photograph until it finishes loading. Local imports emit AVIF then WebP via Sharp; Sanity URLs stay on the image CDN with a width `srcset` (`auto=format`, quality 70). Wired into project gallery slides via `SectionProject`; reuse anywhere an image needs the branded placeholder. Set `stage={false}` on the LCP image so the overlay does not hide it.

## Usage

```astro
---
import ImageLoader from "@components/ImageLoader.astro";
import shot from "@images/project.jpg";
---

{/* Standalone — frame reserves aspect-ratio from the asset */}
<ImageLoader
  src={shot}
  alt="Project photograph"
  widths={[720, 1280]}
  sizes="40vw"
/>

{/* Parent owns sizing — fill the figure */}
<figure class="relative h-[80svh] overflow-hidden" style={`aspect-ratio: ${shot.width} / ${shot.height}`}>
  <ImageLoader
    src={shot}
    alt="Project photograph"
    class="absolute inset-0 size-full"
    preserveAspect={false}
    loading="eager"
    fetchpriority="high"
  />
</figure>
```

## Behavior

- Local imports emit AVIF then WebP via `OptimizedPicture` (Sharp at build). Sanity URLs render a CDN `srcset` with `auto=format` at quality 70.
- Stage uses `bg-secondary/80` so the brand secondary swatch fills the frame at 80% opacity while the photo decodes.
- Reduced-motion users skip the fade and reveal immediately.
- Cached images (`img.complete`) skip the stage without waiting for a load event.
- `stage={false}` skips the overlay so an LCP photograph can paint immediately. An optional `placeholder` LQIP still fills the frame.
- Without JS, a `<noscript>` rule hides the stage so the photograph stays visible.
