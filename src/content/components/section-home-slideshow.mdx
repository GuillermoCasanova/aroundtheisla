## Behavior

- GSAP ScrollTrigger pins the viewport and scrubs the track `x` so images move **right → left** as the user scrolls down.
- First image is the LCP candidate (`loading="eager"` + `fetchpriority="high"`).
- `prefers-reduced-motion: reduce` skips the pin and falls back to native horizontal scroll-snap.
- Full-bleed on purpose — does not wrap `SectionMain`, so the pin matches the edge-to-edge Figma composition.

## Tokens

- Surfaces: `bg-canvas`, veil `bg-panel-muted/40`
- Type/role colors inherit from the page theme
- Motion: GSAP scrub (no hardcoded duration/easing in CSS beyond the reduced-motion path)
