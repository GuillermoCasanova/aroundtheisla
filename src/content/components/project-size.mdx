Radiogroup used on the project rail, directly under the title. Selecting an option writes `data-size` on the closest `[data-project]` ancestor so the gallery can change column width. The last choice is stored under `ati-project-size`. All three labels share one text size and sit on the same baseline.

## Mechanism

- ARIA radio pattern: `role="radiogroup"` on the wrapper, `role="radio"` + `aria-checked` on each button, roving `tabindex`.
- Arrow keys, Home, and End move the selection. Click and keyboard both persist the choice.
- Dispatches a bubbling `project:size` event with `{ size }` so a parent can react without reading the DOM.
- Labels are the same size (`text-body-md`); the selected label uses `text-fg`, idle labels use `text-fg-muted`.

## Usage

```astro
</section>
```

## Notes

- Without a `[data-project]` ancestor the radios still update visually; only the gallery width contract is skipped.
