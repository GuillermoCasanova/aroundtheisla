A site footer with a single right-aligned copyright line. Layouts include it by default; a page can omit it with `hideFooter`.

## Props

<PropsTable props={[
  { name: "copyright", type: "string", default: "site.copyright", description: "Copyright line. `{current_year}` is replaced with the current year. Defaults to the value in `src/data/site.ts`." },
  { name: "class", type: "string", description: "Optional class passthrough on the `<footer>`." },
]} />

## Usage

Layouts render the footer. Pass `hideFooter` to omit it:

```astro
---
import Layout from "../layouts/Layout.astro";
---

<Layout title="Work">
  <main id="main">{/* page content */}</main>
</Layout>
```

```astro
<Layout title="Home" hideFooter>
  <main id="main">{/* no footer */}</main>
</Layout>
```

CMS pages expose the same control as **Hide footer** on the Sanity page document. Home is hidden; other pages keep the footer unless an editor turns it off.

## Layout

Left-aligned copyright, padded with `px-site-margin` so it lines up with the page box.

## A11y

Wrapped in a native `<footer>`. The copyright text is the accessible name of the region.

## Tokens

- Type: `text-body-sm text-fg-muted`.
- Horizontal padding: `px-site-margin`.
- Vertical padding: `py-6`.

## Notes

- Copyright copy lives in Sanity (`footerSettings`) or `src/data/site.ts` (`site.copyright`), not in the component.
- `{current_year}` in that copy is replaced with the visitor's year in JS; the build year is the no-JS fallback.
- No live preview here — the footer is a page-edge landmark. View any inner page to see it in context.
