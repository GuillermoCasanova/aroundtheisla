Figma Home (`222:21`): a white canvas and one photograph, centered. The shot is chosen at random from the homepage's Sanity hero photographs (up to 5) whenever the page loads. Each shot has a wide desktop crop and a taller mobile crop; a `<picture>` element serves one file. Brand + menu stay in `NavInline`.

## Layout

- Full-viewport on purpose — does not wrap `SectionMain`, so the crop matches the edge-to-edge Figma composition.
- Images are authored on the Home document in Studio (`Hero photographs`) as desktop + mobile pairs. The desktop crop is used from 768px up.
- Without JavaScript the first photograph is shown.
