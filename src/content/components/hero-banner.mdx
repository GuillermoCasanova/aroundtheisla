Full-bleed photo hero. Pass `image` from a CMS photograph or an imported asset. Brand + menu stay in `NavInline` — this component is the media plane only. The homepage itself uses `SectionHomeHero`.

## Props

<PropsTable props={[
  { name: "image", type: "ImageMetadata | CmsImage", description: "Photograph — imported asset or Sanity image." },
  { name: "alt", type: "string", description: "Accessible description of the image. Falls back to the CMS alt." },
  { name: "projectName", type: "string", default: '""', description: "Lower-right label. Pass an empty string to hide it." },
  { name: "ariaLabel", type: "string", default: '"Featured project"', description: "Accessible name for the section landmark." },
  { name: "priority", type: "boolean", default: "true", description: "LCP treatment — eager load + high fetch priority. Set false when something else owns LCP." },
  { name: "class", type: "string", description: "Extra classes on the section root." },
]} />

## Usage

```astro
---
import HeroBanner from "@components/HeroBanner.astro";
---

<HeroBanner image={projectCover} projectName="Around 1" alt="Night crowd, film grain" />
```

## Layout

- Full-bleed on purpose — does not wrap `SectionMain`, so the crop matches the edge-to-edge Figma composition.
- Place under a layout whose nav can sit over the photograph (e.g. light type on a dark photo). `NavSimple` owns the wordmark + menu; do not duplicate them here.

## Tokens

- Surface fallback: `bg-canvas`
- Project label: `text-fg/60`, `text-body-xsm`, uppercase (pair with a dark page theme so type stays light on the photo)
- Spacing: `clamp` insets aligned with the homepage slideshow gutters
