## Layout

- Full-bleed on purpose — does not wrap `SectionMain`, so the crop matches the edge-to-edge Figma composition.
- Place under a layout whose nav can sit over the photograph (e.g. light type on a dark photo). `NavSimple` owns the wordmark + menu; do not duplicate them here.

## Tokens

- Surface fallback: `bg-canvas`
- Project label: `text-fg/60`, `text-body-xsm`, uppercase (pair with a dark page theme so type stays light on the photo)
- Spacing: `clamp` insets aligned with the homepage slideshow gutters
