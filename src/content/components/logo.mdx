The AroundTheIsla SVG wordmark. All paths use `fill="currentColor"`, so color is driven by the parent's `text-*` utility. Used in the site header and as the signature under the about bio — edit `Logo.astro` once and both update.

## Mechanism

- The SVG ships at `132×17` with `viewBox="0 0 132 17"`. Pass `h-*` + `w-auto` to scale it while keeping the aspect ratio.
- Every path uses `fill="currentColor"` — the wordmark inherits its color from the nearest ancestor with a `color` value (i.e. any Tailwind `text-*` utility).
- `aria-label="aroundtheisla"` and `role="img"` make it announce as a single image to assistive tech. Pass `decorative` to hide it when a parent already provides the name.

## Usage

```astro
---
import Logo from "@components/Logo.astro";
---

<Logo class="h-4 w-auto" />

<div class="text-canvas">
  <Logo class="h-8 w-auto" />
</div>
```

## Notes

- Use `h-*` together with `w-auto` to size the logo. Without `w-auto`, a height-only class can squash the viewBox.
- The trailing period is part of the path data — not a separate text run.
