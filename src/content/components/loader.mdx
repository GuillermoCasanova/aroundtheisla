Site intro loader from the Figma Loader frame: a blank stage with the palm mark centered. Wired into `Layout` by default; dismisses after hero and above-the-fold images have loaded and decoded (honoring a minimum dwell) and skips on return visits within the same session.

## Layout

Pass `skipLoader` on `Layout` to opt a page out (useful for docs or error pages). The overlay is otherwise included on every page.

## Behavior

- Covers the viewport with `bg-panel` / `text-fg` so themes invert correctly. Sits above nav (`z-100`).
- Waits for above-the-fold images: `fetchpriority="high"`, `[data-loader-wait]`, or in-viewport images that are not `loading="lazy"`. Each image is loaded and `decode()`d before dismiss. Hidden hero alternates are skipped. A safety cap (8s) prevents a hung request from trapping the page.
- Palm mark breathes gently while waiting; reduced-motion users get a static mark and an immediate exit.
- Locks document scroll while visible; restores on dismiss.
- `role="status"` + visually hidden “Loading”; `inert` while covering the page.
- Without JS, a `<noscript>` rule hides the overlay so the page stays usable.
